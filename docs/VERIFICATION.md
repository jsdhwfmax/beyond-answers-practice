整理中修正了两处影响复现的依赖／兼容问题：

- 历史题库测试原本读取内部归档。公开版改为 `tests/fixtures/campus-v1-fingerprints.json` 的 180 条原版本 ID 与 SHA-256 指纹，继续核对每题全部字段不被改写，不额外附一份历史回答正文。

另一次同时进行类型、lint 和测试的运行中，过期尝试测试未在等待窗口内观察到待定状态。保留这次失败；没有放宽其断言。随后顺序运行完整单元测试，**828 项中 827 通过、0 失败、1 跳过**，包含十并发幂等与过期尝试检查。跳过项仅为缺少独立 `TEST_DATABASE_URL` 的 PostgreSQL 集成检查。类型与 lint 检查通过。

仓库提供合成测试用例，读者可按 README 运行；需要真实 API 的评估命令与普通测试明确分开。本轮没有重跑浏览器全套、真实模型或数据库集成。最初使用外部依赖 junction 的构建被 Turbopack 拒绝，改为独立离线安装后，默认 Next.js 生产构建通过。公开目录的本地源码导入、图片引用和文档链接检查也通过；依赖目录和生成文件不进入发布清单。
